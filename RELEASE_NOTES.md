Three build puzzles, one tiny robot.

- Reconcile a merge conflict without dropping behavior.
- Stop a recurring fake timer after three heartbeats.
- Repair a bounded retry policy and its backoff.
- Arrow-key terminal UI, plain accessible mode, and deterministic demo.
- Node.js 20+, no runtime dependencies, network calls, subprocesses or saved files.

Download the package tarball and SHA256SUMS below, or launch from the tagged GitHub source:

```sh
npx --yes --package=github:aporkolab/build-escape#v1.0.0 build-escape
```

The npm registry is not used to distribute this package.
